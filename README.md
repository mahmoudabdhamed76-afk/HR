# EmdadX HR Frontend

واجهة ثابتة جاهزة للرفع على GitHub وRailway.

## التشغيل المحلي
```bash
npm install
npm start
```

## النشر على Railway
- ارفع الملفات إلى GitHub
- اربط الريبو في Railway
- Railway سيقرأ `package.json` و`railway.json`
- أو استخدم `nixpacks.toml` إذا كنت تفضّل Nixpacks

## الملفات الأساسية
- `index.html`
- `server.js`
- `package.json`
- `nixpacks.toml`
- `railway.json`
